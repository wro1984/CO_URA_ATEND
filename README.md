# URA · Suporte B2C

App do celular com os alarmes e as filas do Suporte B2C na URA (CO e TEL): **Alarmes**, **Agora**, **Evolução** e
**Skills**, ao vivo pelo Genesys Pulse e com o histórico de 139 dias.

- Endereço: <https://wro1984.github.io/CO_URA_ATEND/> (abra pelo **HUB dos apps**: o login é o do HUB).
- Os dados são publicados **cifrados** pelo MAPI (Comunicação → URA Atendimento · App). Quem vê é definido no perfil do HUB.
- As telas e as regras são as do app de homologação (`vivo61991-tech/ura-atendimento`). Para quem mantém: [`CLAUDE.md`](CLAUDE.md).
