# URA Atendimento

App do celular com o atendimento da URA (Suporte B2C): **Agora**, com os números do Genesys Pulse, e **Histórico** dos
últimos 90 dias, os dois comparados com a média das 7 semanas anteriores no mesmo dia da semana. Mostra o Total, o CO e a
TEL, por grupo e por skill.

- Endereço: <https://wro1984.github.io/CO_URA_ATEND/> (abra pelo **HUB dos apps**: o login é o do HUB).
- Os dados são publicados **cifrados** pelo MAPI (Comunicação → URA Atendimento · App). Quem vê é definido no perfil do HUB.
- Para quem mantém: leia o [`CLAUDE.md`](CLAUDE.md).
